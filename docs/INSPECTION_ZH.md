# 新增：设计模型对比与构件安装偏差

## 实际完成的功能

`config/design.json` 描述一个已知尺寸的矩形构件，包含设计位置、角度和容差。设计已位于 `demo_map` 坐标系；本版本不估计设计到地图的配准。

`inspection.py` 从估计位姿变换后的激光点中：

1. 排除距离基线地图小于18厘米的表面。
2. 在设计中心1.2米范围内收集候选点并降采样。
3. 至少观测3帧、25个点后，用鲁棒非线性最小二乘拟合已知尺寸矩形的边界。
4. 检查残差、参数边界和雅可比的奇异值，拒绝明显欠约束的拟合。
5. 对比估计中心与设计中心，计算二维位置和角度偏差。
6. 输出供规划器读取的JSON状态。

拟合初值来自设计位姿；中心搜索范围为各轴±0.5米，角度±25度。这是局部匹配，不能找到任意位置的构件。矩形具有180度对称性，报告的是靠近设计角度的局部解。

## 查看结果

```bash
.demo-venv/bin/python -m construction_slam.demo --gif
cat artifacts/construction_state.json
```

- `overview.png` / `demo.gif`：紫色虚线是设计轮廓，红线是估计轮廓。
- `construction_state.json`：最新状态，包含构件ID、位姿、偏差、最后观测帧和建议动作。
- `inspection_history.json`：每帧状态，便于检查何时证据充足、何时检测到偏差。

| 状态 | 含义 | 建议动作 |
|---|---|---|
| insufficient_evidence | 点少、视角不足或拟合不可靠 | 继续观察 |
| within_tolerance | 当前拟合偏差在容差内 | 经复核后继续 |
| deviation_detected | 位置或角度超限 | 请求检查放置位置 |
| stale_observation | 已有拟合，但超过30帧没有新增观测 | 重新观察 |

默认容差为8厘米和5度，仅为演示参数，不是工程标准。`next_action` 是接口建议，没有真正驱动规划器或机器人。

## 仿真真值与算法结果

仿真将构件相对设计平移世界坐标 `[+0.12, -0.08]` 米，旋转8度，真实平移偏差为14.42厘米。这个实际位姿只存在于仿真模块，不传入检测器。设计配置中的预先对齐属于明确假设。

seed 7的最终拟合约为13.27厘米、8.17度。误差包含激光噪声、定位误差和部分可见表面造成的影响，不能推广到真实机器人。

## 限制与学习实验

只处理一个静止、已知尺寸的二维矩形，没有语义识别、多构件数据关联、三维6DoF姿态或CAD/BIM解析。候选区域内的其他物体会污染拟合；历史点会一直累积，所以不支持构件放置后持续移动。没有完整概率不确定度，奇异值门限只是启发式质量检查。

建议亲自做三组实验：把仿真偏差改成0、把容差改小、只保留一个可见平面。解释为什么三者应分别得到“合格”“偏差超限”“证据不足”。可先阅读 `tests/test_inspection.py` 中对应测试。
